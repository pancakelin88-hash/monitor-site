# LinYH · PHASE STRIKE

打开 `index.html` 即可游玩，无需安装依赖。

## 操作

- 桌面：WASD 或方向键移动，P / Esc 暂停
- 手机：按住并拖动战机
- 射击：全程自动射击

## 游戏系统

- 九类敌机（侦察、折线、重装、狙击、无人机、突击枪骑、幻影、航母、精英）与五波一次的 Boss 战；高阶敌机按波次解锁
- 武器、护盾、维修三类掉落
- 连击倍率、擦弹奖励、波次升级与最高分记录
- 六类高精度俯视飞船精灵、多层星云、战机残影与能量护罩
- 休闲、标准、极限三档难度与可选作弊模式
- 相位突进、短暂无敌和动态 2.5D 透视航道
- 粒子爆炸、受击闪光、屏幕震动、伤害数字
- 高响应触控、单实例动画循环与移动端性能优化
- 合成音效、设备震动与低动态偏好支持
- 局内主动技能栏：棱镜弹幕、虚空长枪、离子新星、太阳燃域；支持 1–4 热键与触控，带冷却、透视光束、空间环和燃烧领域反馈
- 武器上限提升至 24 级；HUD 用 12 段双色/多色分段显示，每段代表 2 级，并显示当前等级与上限
- 子弹形态：脉冲、扇刃、针束、能量球、环刃、棱晶、液态铬、星云螺旋；不同模块会同步改变挂点、颜色、尾焰和爆炸色
- 2.5D / 3D 视觉层：消失点航道、深度扫描线、体积棱镜、轨道环与 Bloom；移动端自动降级为轻量网格
- 机体变形：按 `T` 或点击 `T · 变形` 展开机械翼面、核心轨道和多重武器挂点；战斗形态提高移动速度、弹幕数量与伤害，冷却后可切回巡航形态
- 详细部件目录：8 套主武器模块、4 套护甲/反应堆模块、12 个 VFX 插槽；局内模块掉落会切换弹体形态、挂点、颜色、尾焰与核心等级
- 战机等级进化：AETHER → PRISM WING → VOID HALO → SINGULARITY；升级同步改变机翼、轨道环、核心与属性
- 六套战机专属动态背景包登记在 `assets/backgrounds/ship-backgrounds.json`；完整制作工作流见 `TOOLCHAIN.md`
