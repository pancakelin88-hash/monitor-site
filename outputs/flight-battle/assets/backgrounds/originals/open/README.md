# Open background sources

These downloaded masters are kept for reproducible re-encoding. Runtime loads
the smaller WebP derivatives in `../../`. All listed pages explicitly mark the
image Public Domain or CC0; NASA/STScI/ESA credits are retained in
`../../motion-backgrounds.json`.
